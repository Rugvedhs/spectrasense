# Figure and table index

Every figure and every result CSV is regenerated by a script from the raw stage
outputs in `results/`: most by `scripts/analyze.py`, the curation and family
composition tables by `scripts/prepare_features.py`, Table 13's source by
`scripts/run_calibration_study.py` and the supplementary Table S1 by
`scripts/make_supplementary.py`. Figures are written as vector PDF (for
typesetting) and PNG (for inspection). The fourteen tables typeset in the body of
the manuscript are transcriptions of the CSV named in each caption;
`scripts/check_manuscript_tables.py` asserts every one of their cells against
that CSV and runs as part of `pytest tests`. The one exception, flagged in its
own caption, is the left-hand column of Table 1, which is transcribed from the
prior analysis cited as [Teh] and is not an output of this pipeline.

## Main figures

| # | File | Shows |

The figure form of Table 8: the taxonomy allocates width differently, it does not spend less of it. |
| 7 | `figures/fig7_error_vs_similarity.pdf` | Absolute error against nearest-training similarity, random vs family holdout, with SEM error bars. |

## Regenerating

```bash
python scripts/prepare_features.py
./scripts/run_all.sh random scaffold cluster family
N_REPEATS=3 ./scripts/run_all.sh matched
python scripts/run_benchmark.py --stage random --representation morgan \
    --models extra_trees --suffix _morgan --n-repeats 5
python scripts/run_benchmark.py --stage family --representation morgan \
    --models extra_trees --suffix _morgan
python scripts/run_calibration_study.py
python scripts/make_supplementary.py
python scripts/analyze.py
```
