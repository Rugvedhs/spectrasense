# Figure and table index

Every item is regenerated by `python scripts/analyze.py` from the raw stage
outputs in `results/`; nothing is hand-entered. Figures are written as vector PDF
(for typesetting) and PNG (for inspection).

## Main figures

| # | File | Shows |
|---|---|---|
| 1 | `figures/fig1_dataset.pdf` | Reported *T*~g~ distribution by backbone family, ordered by median, with family sizes. Establishes that the derived taxonomy is chemically sensible. |
| 2 | `figures/fig2_generalization_gap.pdf` | Test MAE by model and split regime, with across-repeat error bars. The protocol-over-model result. |
| 3 | `figures/fig3_matched_design.pdf` | Matched arms on an identical test set (left) and the size-controlled family effect per family (right). The causal result. |
| 4 | `figures/fig4_coverage.pdf` | Marginal coverage (left) against worst similarity-band coverage (right), by conformal method and regime. |
| 5 | `figures/fig5_coverage_vs_similarity.pdf` | Conditional coverage against nearest-training similarity, one panel per regime. The mechanism figure. |
| 6 | `figures/fig6_width_tradeoff.pdf` | Worst-band coverage against mean interval width. Shows the repair is not bought with width. |
| 7 | `figures/fig7_error_vs_similarity.pdf` | Absolute error against nearest-training similarity, random vs family holdout. |

## Regenerating

```bash
python scripts/prepare_features.py
./scripts/run_all.sh random scaffold cluster family
N_REPEATS=3 ./scripts/run_all.sh matched
python scripts/run_benchmark.py --stage random --representation morgan \
    --models extra_trees --suffix _morgan --n-repeats 5
python scripts/run_benchmark.py --stage family --representation morgan \
    --models extra_trees --suffix _morgan
python scripts/run_calibration_study.py
python scripts/make_supplementary.py
python scripts/analyze.py
```
